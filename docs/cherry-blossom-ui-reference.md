# Dear App UI Direction

## 목적
제공된 디자인 시안 8장을 기준으로 Dear 앱이 앞으로 따라갈 시각 언어와 화면별 구현 기준을 고정한다.

## 핵심 무드
- 따뜻하고 사적인 커플 공간: 감성적이지만 기능은 또렷해야 한다.
- 벚꽃 핑크, 코랄 그라데이션, 깨끗한 화이트 카드, 아주 옅은 로즈 배경을 기본으로 한다.
- UI는 넓은 여백, 큰 라운드, 얇은 핑크 보더, 부드러운 그림자, 말랑한 아이콘 버블을 반복한다.
- 3D 로고/마스코트/하트/꽃잎 장식은 핵심 화면의 정서적 포인트로 사용하되, 입력과 읽기 영역을 방해하지 않는다.
- 사진은 앱의 감정적 중심이다. 앨범/홈/채팅/지도에서 실제 사진 썸네일을 충분히 크게 보여준다.

## 토큰 기준

### Color
- `primary`: `#E85D8B`
- `primarySoft`: `#F7A8BD`
- `primaryDeep`: `#D94B75`
- `surface`: `#FFFFFF`
- `surfaceTint`: `#FFFBFD`
- `surfaceRaised`: `#FFF7F9`
- `surfaceAccent`: `#FDE8EF`
- `textMain`: `#2D1B24`
- `textSub`: `#6E4D5D`
- `textMuted`: `#8C6F7A`
- `line`: `#F2D6DF`
- `mapBlue`: `#DDEAF1`
- `successPastel`: `#B8E2D2`
- `warningPastel`: `#FFDFAE`
- `purplePastel`: `#D9B6EA`
- `error`: `#D64545`

### Radius
- `r14`: 작은 칩/태그/아이콘 버블
- `r18`: 버튼/입력
- `r22`: 기본 카드/입력바
- `r30`: 큰 비주얼 카드/바텀시트
- `pill`: D-day 배지, 세그먼트, 메시지 리액션

### Spacing
- 8pt 기반: 4, 8, 12, 16, 20, 24, 32
- 모바일 좌우 기본 inset은 20~24px로 넉넉하게 둔다.

### Border / Shadow
- border: `0.6~1.0px`, `outlineVariant`
- shadow: 카드가 배경에서 살짝 뜨는 정도. 강한 드롭섀도는 피한다.
- 큰 카드/하단 시트는 반투명 핑크 보더와 blur 16~24px 그림자를 사용한다.

### Typography
- 제목: 굵고 둥근 인상, 24~34px 범위. 핵심 수치(D+128, 24%)는 48~72px까지 키운다.
- 본문: 15~18px, 진한 브라운 블랙을 기본으로 한다.
- 보조문구: 13~16px, muted 색상. 안내는 짧고 다정하게 쓴다.
- 버튼 라벨은 16~18px, `w700~w800`.

## 화면별 적용 가이드

## 1) 인증(Auth)
- 첫 화면은 로고와 "둘만의 공간" 메시지를 중앙에 크게 둔다.
- 로그인/회원가입 세그먼트는 넓은 pill 형태로, 선택 탭은 흰색 raised pill로 표현한다.
- 입력 필드는 흰색, r18, 얇은 핑크 보더, 좌측 라인 아이콘을 사용한다.
- 기본 CTA는 좌우 코랄 그라데이션의 큰 버튼이다.
- Apple 로그인 버튼은 흰색 카드형 버튼으로 분리한다.

## 2) 페어링(Pairing)
- "둘이 연결되면 우리만의 공간이 열려요"처럼 감성 카피를 상단에 둔다.
- "내 초대 코드"와 "상대 코드 입력"은 큰 흰색 카드 2개로 분리한다.
- 초대 코드는 4자리 대문자를 매우 큰 코랄 타이포로 보여준다.
- 코드 입력칸은 4개의 독립 박스, 현재 포커스는 코랄 보더로 표시한다.
- 복사/공유/새 코드 생성은 작은 outline pill 버튼으로 구성한다.

## 3) 채팅(Chat)
- AppBar는 상대 아바타, 이름, 채팅방 서브텍스트, D-day pill, 더보기 버튼을 포함한다.
- 상대 말풍선은 흰색, 내 말풍선은 아주 옅은 핑크로 구분한다.
- 시간은 말풍선 옆에 작고 흐리게 둔다.
- 리액션은 하트 아이콘 + 숫자의 작은 pill로 말풍선 아래에 붙인다.
- 이미지 메시지는 큰 라운드 썸네일로 보여주고 공유/확대 액션을 둔다.
- 사진 선택 상태는 하단 바텀시트로 올리고, 썸네일마다 삭제 x를 제공한다.
- 입력바는 하단 플로팅 흰색 pill, 좌측 사진 버튼, 우측 코랄 원형 전송 버튼이다.

## 4) 홈(Home)
- 상단은 Dear 로고, 알림 아이콘, 인사말, 커플 아바타 두 장과 하트로 구성한다.
- 메인 D-day 카드는 큰 코랄 수치와 마스코트/일러스트가 들어간 핑크 gradient 카드다.
- 채팅 미리보기 카드는 아이콘, 방 제목, 뱃지, 마지막 메시지, 시간, unread dot를 보여준다.
- 최근 추억은 가로 썸네일 스트립으로 먼저 보인다.
- 기능 진입은 2열 카드 그리드. 아이콘 버블 + 제목 + 짧은 설명 + chevron을 반복한다.
- 하단 탭은 홈/채팅/앨범/더보기 또는 홈/앨범/중앙 추가/기념일/설정처럼 화면 맥락에 맞추되, 선택 항목은 코랄로 강조한다.

## 5) 기념일(Anniversary)
- 상단 히어로 카드는 D+수치, 시작일, 커플 아바타, Dear 링 그래픽을 조합한다.
- 기념일 목록은 타임라인 점/라인과 큰 흰색 카드 리스트를 결합한다.
- 각 항목은 원형 아이콘, 제목, 날짜, D-day chip, 알림 버튼, chevron을 포함한다.
- 추가 액션은 화면 하단 중앙의 코랄 원형 + 버튼으로 시각적 중심을 만든다.

## 6) 여행 지도(Travel Map)
- 지도 자체는 부드러운 파스텔 지도 타일을 쓰고, 방문 지역은 코랄 계열로 칠한다.
- 방문률 카드는 좌상단에 floating card로 배치한다.
- 선택 지역은 하단 large bottom sheet에서 편집한다.
- 색상 선택은 원형 swatch, 방문일은 calendar input, 메모는 textarea, 사진은 정방형 썸네일 row로 구성한다.
- 삭제/저장은 하단에 나란히 둔다. 삭제는 outline, 저장은 filled gradient.

## 7) 오목(Omok)
- 게임 대기/기록/최근 경기/보드는 모두 카드 단위로 정리한다.
- 주요 액션 "신청하기"는 코랄 filled 버튼, 취소/기권은 outline 또는 연한 핑크 버튼이다.
- 보드는 따뜻한 나무 질감과 부드러운 입체 돌을 사용한다.
- 턴/시간/상대 차례 상태는 보드 위에 명확한 chip과 dot으로 보여준다.

## 8) 추억 앨범(Memory Album)
- 대표 앨범은 큰 사진 카드와 "대표 앨범" badge로 보여준다.
- 새 앨범 만들기는 별도 넓은 outline card로 배치한다.
- 최근 추억은 3열 정방형 그리드, 이미지 라운드는 12~16px.
- 중앙 추가 버튼이 있는 탭 구조에서는 플로팅 코랄 원형 버튼을 유지한다.

## 접근성 체크
- 텍스트 대비 4.5:1 이상
- 터치 타깃 최소 44px
- 오류 텍스트는 색 + 문구 동시 전달
- 코랄 텍스트를 연한 핑크 배경 위에 쓸 때는 충분히 진한 색을 선택한다.
- 장식 이미지와 지도 배경 위 텍스트는 반드시 카드/오버레이로 대비를 확보한다.

## 구현 우선순위
- P0: 공통 토큰(`DearColors`, `DearRadii`, `DearCard`, `DearGradientButton`)을 시안 기준으로 유지한다.
- P1: 인증, 페어링, 홈, 채팅, 앨범, 기념일의 핵심 화면을 같은 카드/입력/버튼 언어로 통일한다.
- P2: 지도/오목처럼 도메인 특성이 강한 화면은 기능성을 먼저 지키고, 색/카드/버튼만 Dear 톤에 맞춘다.
- P3: 마스코트, 꽃잎, 3D 로고 등 장식 자산을 실제 앱 asset으로 정리한다.
